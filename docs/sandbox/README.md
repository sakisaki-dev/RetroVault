# Trading Floor has moved

The card-market simulation that lived in `sandbox/` and `docs/sandbox/` is now its own research project:
**[sakisaki-dev/trading-floor](https://github.com/sakisaki-dev/trading-floor)**.

Its full history moved with it. The fan site does not depend on it. Its data files were built from this repository's
`public/data/` and `data/y80/`; the rebuild steps are in the new repository's `docs/DATA.md`.
